# Data Science Job Posting Analysis Using NLP

This repository contains a final project for a data mining course in a Master
of Science in Analytics program. The project is focused on analyzing data
science job postings using natural language processing (NLP).

## Repository contents

- `Final_Project.html` — saved GitHub page for the final project.
- `Data Mining Final Presentatiom_FINAL.pdf` — saved GitHub page for the final
  project presentation.

**File format note:** Both files currently contain HTML page captures, despite
their `.html` and `.pdf` extensions. They are not the original HTML report or a
PDF presentation.

## Running the project

This repository does not currently include runnable source code, a dataset, or
dependency/setup instructions. The saved page captures can be opened in a web
browser, but the project itself cannot be reproduced from the files currently
checked in.
